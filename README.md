# AurelyStudio ADHD Budget Planner

A responsive personal budget planner for dated income, recurring paydays, bills, spending, savings goals, debt progress, forecasts, notes, themes, backups, printing, and offline use.

- GitHub Pages: https://billionar.github.io/aurelystudio-adhd-budget-planner/

Records stay in the current browser unless the user exports and restores a JSON backup. The app does not connect to a bank or provide automatic cloud sync.
